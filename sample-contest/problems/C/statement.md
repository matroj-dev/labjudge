# 圆的面积

输入一个整数 `r`（1 ≤ r ≤ 1000），输出半径为 `r` 的圆的面积。

面积请用双精度浮点数输出，**与标准答案的相对或绝对误差不超过 1e-6 都算正确**。

本题带 SPJ（special judge）：答案不唯一（写法五花八门，比如 `3.14159`、`3.141592653589793`、
`3.14159265358979323846` 都对），所以不能按字符串比对，必须由 `checker.cpp` 判断。

## 输入格式

一行一个整数 `r`。

## 输出格式

一行一个实数，表示面积。

## 样例

输入

```text
1
```

输出

```text
3.14159265358979
```
